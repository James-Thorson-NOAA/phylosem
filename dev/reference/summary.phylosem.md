# summarize phylosem

Summarize phylosem output from phylosem, including calculating
intercepts at the tree root

## Usage

``` r
# S3 method for class 'phylosem'
summary(object, ...)
```

## Arguments

- object:

  Output from
  [`phylosem`](https://james-thorson-noaa.github.io/phylosem/dev/reference/phylosem.md)

- ...:

  Not used

## Value

Data-frame containing all estimated intercepts, path coefficients, and
variance-covariance parameters as well as their standard errors
