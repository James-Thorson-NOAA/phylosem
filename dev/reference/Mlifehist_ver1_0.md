# Fisheries natural mortality example

Data used to demonstrate phylogenetic comparative methods for fisheries
science. Specifically a copy of the Then et al. database
[doi:10.1093/icesjms/fsu136](https://doi.org/10.1093/icesjms/fsu136)
using file "Mlifehist_ver1.0.csv" accessed from
<https://www.vims.edu/research/departments/fisheries/programs/mort_db/>

## Usage

``` r
data(Mlifehist_ver1_0)
```
