# Package index

## Specification and fitting

Core tools for model fitting and diagnostics.

- [`phylosem()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/phylosem.md)
  : Fit phylogenetic structural equation model
- [`phylosem_control()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/phylosem_control.md)
  : Detailed control for phylosem structure
- [`beverton_holt()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/beverton_holt.md)
  : Organize stock-recruit time series

## Families

Additional families beyond the standard R families.

- [`fixed()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/fixed.md)
  : Family for data that are known without error
- [`categorical()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/categorical.md)
  : Family for categorical data

## Interpret output

Tools for interpreting output.

- [`summary(`*`<phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/summary.phylosem.md)
  : summarize phylosem
- [`vcov(`*`<phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/vcov.phylosem.md)
  : Extract Variance-Covariance Matrix
- [`print(`*`<phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/print.phylosem.md)
  : Print parameter estimates and standard errors.
- [`coef(`*`<phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/coef.phylosem.md)
  : Extract path coefficients
- [`as_fitted_DAG()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/as_fitted_DAG.md)
  : Convert phylosem to phylopath output
- [`as_phylo4d()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/as_phylo4d.md)
  : Convert phylosem to phylo4d
- [`as_sem()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/as_sem.md)
  : Convert phylosem to sem output
- [`logLik(`*`<phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/logLik.phylosem.md)
  : Extract the (marginal) log-likelihood of a phylosem model

## Model comparison

Tools for selecting and comparing models (based on phylopath)

- [`average()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/average.md)
  : Choose model
- [`choice()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/choice.md)
  : Choose model
- [`best()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/best.md)
  : Extract best fitted model
- [`compare_phylosem()`](https://james-thorson-noaa.github.io/phylosem/dev/reference/compare_phylosem.md)
  : Compare phylogenetic structural equation models
- [`best(`*`<compare_phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/best.compare_phylosem.md)
  : Extract best fitted model
- [`average(`*`<compare_phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/average.compare_phylosem.md)
  : Choose model
- [`choice(`*`<compare_phylosem>`*`)`](https://james-thorson-noaa.github.io/phylosem/dev/reference/choice.compare_phylosem.md)
  : Choose model
