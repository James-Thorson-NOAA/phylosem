# Choose model

Choose model

## Usage

``` r
choice(x, choice)
```

## Arguments

- x:

  output from `compare_phylosem`

- choice:

  Integer indicating model to extract

## Value

Returns chosen model from those fitted using
[`compare_phylosem`](https://james-thorson-noaa.github.io/phylosem/dev/reference/compare_phylosem.md)
