# Print parameter estimates and standard errors.

Print parameter estimates

## Usage

``` r
# S3 method for class 'phylosem'
print(x, ...)
```

## Arguments

- x:

  Output from
  [`phylosem`](https://james-thorson-noaa.github.io/phylosem/reference/phylosem.md)

- ...:

  Not used

## Value

prints (and invisibly returns) output from
[`nlminb`](https://rdrr.io/r/stats/nlminb.html)
