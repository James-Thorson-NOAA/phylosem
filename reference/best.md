# Extract best fitted model

Extract best fitted model

## Usage

``` r
best(x)
```

## Arguments

- x:

  output from
  [`compare_phylosem`](https://james-thorson-noaa.github.io/phylosem/reference/compare_phylosem.md)

## Value

Returns best model from those fitted using
[`compare_phylosem`](https://james-thorson-noaa.github.io/phylosem/reference/compare_phylosem.md)
