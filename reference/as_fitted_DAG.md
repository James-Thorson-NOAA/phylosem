# Convert phylosem to phylopath output

Convert output from package phylosem to phylopath

## Usage

``` r
as_fitted_DAG(object)
```

## Arguments

- object:

  Output from
  [`phylosem`](https://james-thorson-noaa.github.io/phylosem/reference/phylosem.md)

## Value

Convert output to format supplied by
[`est_DAG`](https://ax3man.github.io/phylopath/reference/est_DAG.html)
