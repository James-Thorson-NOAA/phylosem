# Extract path coefficients

Extract path coefficients.

## Usage

``` r
# S3 method for class 'phylosem'
coef(object, standardized = FALSE, ...)
```

## Arguments

- object:

  Output from
  [`phylosem`](https://james-thorson-noaa.github.io/phylosem/reference/phylosem.md)

- standardized:

  Whether to standardize regression coefficients

- ...:

  Not used

## Value

Data-frame listing all path coefficients, their parameter index and
estimated values
