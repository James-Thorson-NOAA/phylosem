# Convert phylosem to sem output

Convert output from package phylosem to output from package sem

## Usage

``` r
as_sem(object)
```

## Arguments

- object:

  Output from
  [`phylosem`](https://james-thorson-noaa.github.io/phylosem/reference/phylosem.md)

## Value

Output converted to format supplied by
[`sem`](https://rdrr.io/pkg/sem/man/sem.html)
